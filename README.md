# hire-me

Personal landing page for **Ankit Kumar**, Machine Learning Engineer.

Reached via QR code on a marathon runner's vest. Built to load instantly on a phone and make the LinkedIn button impossible to miss.

**Live:** https://ankitkr8540.github.io/hire-me

---

## Stack

Static HTML + CSS — no build tools, no frameworks, no JavaScript dependencies.
Deploys automatically from the `master` branch via GitHub Pages.

## Files

| File | Purpose |
|---|---|
| `index.html` | All page content and structure |
| `styles.css` | Mobile-first styles |
| `assets/favicon.svg` | "AK" lettermark favicon |
| `Kumar_Ankit_Resume.pdf` | Résumé served directly from the repo |

## Local preview

Open `index.html` directly in a browser — no server required.

## Updating

| What to change | Where |
|---|---|
| Copy or links | `index.html` |
| Styles | `styles.css` |
| Résumé | Replace `Kumar_Ankit_Resume.pdf` and push |

After any edit: `git add . && git commit -m "your message" && git push`

GitHub Pages rebuilds in ~60 seconds.

## Analytics

Button clicks are tracked via `data-umami-event` attributes on each CTA.
To activate, add your Umami script tag to the `<head>` in `index.html`.
